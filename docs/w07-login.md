## ユーザー登録 /register
- 画面：GET /register、POST /register
- 名前：必須。「名前を入力してください」
- メールアドレス：必須・メール形式・未登録。「メールアドレスを入力してください」「メールアドレスの形式で入力してください」「このメールアドレスはすでに登録されています」
- パスワード：8文字以上。「パスワードは8文字以上で入力してください」
- パスワード確認：パスワードと一致。「パスワードが確認用と一致しません」
- 成功したら：登録したユーザーでログインし、/entries へ移動
## ログイン /login
- 画面：GET /login、POST /login
- メールアドレス：必須
- パスワード：必須
- 認証に失敗したら：「メールアドレスかパスワードが違います」と表示し、入力したメールアドレスを残す
- 成功したら：/entries へ移動し、セッションを再生成する

## ログアウト
- 操作：POST /logout
- 成功したら：ログアウトしてセッションを無効化し、/login へ移動する

## 未ログイン時のアクセス
- 未ログインで /entries、時間割の登録・削除、/courses にアクセスしたら /login へ移動する
## 確かめる項目
- [ ] ログインせずに /entries を開く → /login に移動する
- [ ] パスワードを7文字で登録する → 登録画面に戻り、「パスワードは8文字以上で入力してください」と表示される
- [ ]名前を空欄で登録する　→　登録画面で「名前を入力してください」と表示される
- [ ] メールアドレスを空欄・不正な形式・登録済みの値にして登録する → 「メールアドレスを入力してください」「メールアドレスの形式で入力してください」「このメールアドレスはすでに登録されています」と表示される
- [ ] パスワード確認を違う値にして登録する → 登録画面で「パスワードが確認用と一致しません」と表示される
- [ ] 正しい名前・未登録のメールアドレス・8文字以上のパスワードと確認用パスワードで登録する → ログイン状態で /entries に移動する
- [ ] 登録済みのメールアドレスと間違ったパスワードでログインする → 指定のエラー文が表示され、メールアドレス欄には入力したメールアドレスが残る
- [ ] 登録済みのメールアドレスと正しいパスワードでログインする → /entries に移動する
- [ ] ログアウトボタンを押したあと /entries と /courses を開く → どちらも /login に移動する（確認予定）
